# CamHub Frontend

Frontend statis untuk marketplace sewa kamera CamHub. Aplikasi memakai HTML, CSS, JavaScript, dan Vite; tidak memerlukan PHP, Laravel, atau database untuk menjalankan tampilan.

## Menjalankan

```bash
npm install
npm run dev
```

Buka alamat lokal yang ditampilkan Vite. Untuk membuat hasil build:

```bash
npm run build
```

Halaman saat ini adalah prototipe frontend. Aksi masuk, katalog, dan transaksi belum terhubung ke API.
